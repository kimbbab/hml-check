HML 다시 저장 (수식 겹침 해결) — 크롬·엣지 확장

최신판: 2026-11-18 08:18 · 처음 한 번만 코드를 받아 두고, 버튼 밑 업데이트 확인을 누를 때만 새 버전을 받습니다.

  1. hml-resave-extension.zip을 받아 지우지 않을 폴더에 풉니다.
  2. edge://extensions(크롬은 chrome://extensions) → 개발자 모드 켜기 → 압축을 푼 항목 로드 → HML다시저장 폴더 선택.
  3. CMS 문항 수정 화면 왼쪽 아래 한글 다시 저장 버튼을 누릅니다. 처음 한 번은 주소창의 팝업 차단 표시에서 항상 허용을 눌러 주세요.
  4. 한글 편집기가 열려 지문·문제·해답을 차례로 저장하고 닫힙니다(글자 ∽는 수식 ∽로 바꿈). 끝나면 [전체 반영]을 직접 누르세요.
  5. 문항 상세 화면에서 누르면 수정 화면으로 넘어갑니다. 거기서 한 번 더 누르세요.
