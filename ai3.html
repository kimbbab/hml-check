바로 검사 + AI 눈검수 (ver3)

최신판: 2026-11-17 10:27 · 바로 검사(ver2)가 모두 들어 있어서 ver2 확장 대신 이것 하나만 켜면 됩니다.

  1. hml-ai3-extension.zip을 받아 지우지 않을 폴더에 풉니다.
  2. edge://extensions(크롬은 chrome://extensions) → 개발자 모드 켜기 → 압축을 푼 항목 로드 → 푼 HML_AI눈검수 폴더 선택.
  3. 예전 HML 바로 검사(ver2) 확장은 끄기(둘 다 켜 두면 칸이 두 번 뜰 수 있음).
  4. 확장 아이콘(퍼즐 모양 → HML 바로 검사 + AI 눈검수)을 누르면 설정 창이 열립니다. Claude API 키(sk-ant-…)를 넣고 저장 → 키 시험.
  5. CMS 문항 화면에서 ◀ 바로 검사 탭을 열면 위쪽에 보라색 AI 눈검수 칸이 생깁니다. 이 문항 AI 검사를 누르세요.

무엇을 보나

  • HML 캡처(문제·해답)와 HTML 내용의 글자·수식 차이, 바로 검사가 찾은 차이가 진짜인지(표기만 다른지)
  • 체크하면: 문제풀이(AI 답과 HTML 정답 비교), 메타정보(유형정보·성취기준 등이 내용과 맞는지)
  • 캡처 이미지 자체가 깨진 곳(겹침 등)

API 키는 이 PC의 확장 안에만 저장되고 CMS 페이지·GitHub로 가지 않습니다. 문항마다 비용이 들고(Haiku 5.5 기준 보통 1~5원), 결과 아래에 이 문항 금액과 누적 금액이 나옵니다. CMS는 읽기만 합니다.
