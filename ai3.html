바로 검사 + AI 눈검수 (ver3)

최신판: 2026-11-20 09:15 · 바로 검사(ver2)가 모두 들어 있어서 ver2 확장 대신 이것 하나만 켜면 됩니다.

  1. hml-ai3-extension.zip을 받아 지우지 않을 폴더에 풉니다.
  2. edge://extensions(크롬은 chrome://extensions) → 개발자 모드 켜기 → 압축을 푼 항목 로드 → 푼 HML_AI눈검수 폴더 선택.
  3. 예전 HML 바로 검사(ver2) 확장은 끄기(둘 다 켜 두면 칸이 두 번 뜰 수 있음).
  4. 확장 아이콘(퍼즐 모양 → HML 바로 검사 + AI 눈검수)을 누르면 설정 창이 열립니다. Claude API 키(sk-ant-…)를 넣고 저장 → 키 시험.
  5. CMS 문항 화면에서 ◀ 바로 검사 탭을 열면 위쪽에 보라색 칸이 생깁니다. 처음 한 번 HML_DOWNLOAD 폴더 연결을 누르면, 그 뒤로는 문항마다 미리 돌린 눈검수 결과(수정목록.json·ai.json·메타점검.json)가 자동으로 나옵니다. 눈검수를 새로 합친 뒤에는 새로 읽기.
  6. 검수자(꼭 수정 목록): 받은 검수자목록.json을 아무 폴더에 두고, 처음 한 번 그 폴더를 연결하면 빨간 꼭 수정 목록 칸이 생깁니다. 다음 ▶으로 고칠 문항만 차례로 넘기고, 다 고치면 ✓ 완료. 화면 표시 문제·표기만 다른 것은 빼고 눈검수(실제 차이·깨진 문자)와 정답 검사(정답 의심·확인 필요)만 보입니다.
  7. AI 수정본 [수정]: 같은 폴더에 수정본.json(있으면 수정본_승인.json도)을 두고 새로 읽기. 수정 화면에서 초록 수정안 칸의 수정을 누르면 HTML을 붙여넣고, HML 수정안("hml":[{"slot":"question","eq":"바꿀 수식","to":"새 수식"}])이 있으면 한글 편집기를 열어 고친 뒤 저장까지 합니다(팝업 허용). 새 캡처·HTML 탭을 확인하고 반영. 주관식 OMR 정답이 비어 있으면 HTML 정답으로 채웁니다(16 cm → 정답 16, 뒤 수식어 cm). 잘못됐으면 반영하지 말고 새로고침.
  8. 그림 키우기: 옆 칸 그림 줄에서 배율(기본 1.5배)·최대 폭(기본 640px)을 고르고 그림 키우기 → 이 문항 그림이 바뀔 크기로 미리 보임(아직 안 바뀜). 뺄 그림은 체크 해제, 작은 기호 그림(30px 미만)은 저절로 건너뜀 → 이대로 넣기 → HTML 수정 탭에서 확인 → 반영. 마음에 안 들면 되돌리기(새로고침, 저장 안 됨).
  9. 승인: 옆 칸 맨 위 승인(사용)으로 버튼(상세 화면이 아니면 상세로 가서 저장).
  10. 일괄 수정: 옆 칸의 주황 일괄 수정을 열고 문항 수(처음엔 5)를 정해 일괄 시작. 작업 창에서 문항마다 수정 → 반영 → 상세에서 확인 → 승인(사용)을 차례로 합니다. 수정안이 안 맞거나 확인이 안 되면 그 문항은 건너뛰고, 연속 3번 실패하면 멈춥니다. 기록 CSV로 결과 확인. 재검수 목록 남기기를 켜면 고친 문항의 새 HTML이 일괄수정_재검수.json에 쌓이고, PC에서 python 엄격검사.py 재검수 → 실행 --B D:\codex_B → 재검수결과로 그 문항만 캡처를 새로 받아 다시 검사합니다(재검수_결과.csv).
  11. 미리 돌린 결과가 없거나, 고친 뒤 다시 확인할 때만 이 문항 AI 검사를 누르세요(API 비용이 듭니다).

무엇을 보나

  • HML 캡처(문제·해답)와 HTML 내용의 글자·수식 차이, 바로 검사가 찾은 차이가 진짜인지(표기만 다른지)
  • 체크하면: 문제풀이(AI 답과 HTML 정답 비교), 메타정보(유형정보·성취기준 등이 내용과 맞는지)
  • 캡처 이미지 자체가 깨진 곳(겹침 등)

API 키는 이 PC의 확장 안에만 저장되고 CMS 페이지·GitHub로 가지 않습니다. 문항마다 비용이 들고(Haiku 5.5 기준 보통 1~5원), 결과 아래에 이 문항 금액과 누적 금액이 나옵니다. CMS에 쓰는 것은 [수정]·[반영]·[승인]·[일괄 시작]을 누를 때뿐입니다.
